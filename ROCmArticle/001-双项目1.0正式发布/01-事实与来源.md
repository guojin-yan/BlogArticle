## 三、两个库的事实地图

### HIP CSharp API

- 定位：AMD HIP Runtime 与 HIPRTC 的 C#/.NET 直接绑定，同时提供托管所有者和生成式低层 C ABI。
- Core 程序集包名是 `JYPPX.ROCm.HIP.CSharp.API`；主要命名空间是 `JYPPX.ROCm.HipSharp`，不要把项目名当命名空间。
- 低层声明：459 个 HIP Runtime、18 个 HIPRTC；这表示声明数量，不表示 477 个函数全部实机通过。
- 15 TFM 统一公开 API，正式说明列 122 types / 1,372 members。首篇可省略这些统计。
- 使用源生成 `LibraryImport` / 旧目标 `DllImport`，不引入项目自有通用 C++ 桥接层。
- Core 不含原生负载、驱动或强制 Runtime 依赖。可选 Runtime 10.1.0 提供用户态闭包，不含完整数学库、驱动或 .NET。
- 正式 Windows HIP Runtime 的五个 DLL 具有 AMD 官方签名；这不是对所有 MIGraphX Windows 引擎的签名声明。
- 公开 Runtime 10.1.0 + Core 1.0.0 的包用例：Windows 23 通过 / 1 能力跳过；Linux/WSL 21 通过 / 2 能力跳过。取自当前 Runtime 发行指南，不能扩展为全函数覆盖或当前 Core KFD 验证。
- 典型托管对象：Runtime/Device、设备与锁页内存、Stream/Event、Module/Kernel、Graph、HIPRTC。
- 正式发布记录确认 2026-11-17 已在 NuGet 发布，公开包签名与候选非签名内容已核对。
- 已知原生限制包括 typed 2D fill、driver bitcode linker、Windows batch / external-semaphore graph、primary context 与 legacy border-color 等，详见上游问题登记。文章无需逐条展开，必须保留指向。

### MIGraphX CSharp API

- 定位：MIGraphX 模型解析、编译、张量与执行的 C#/.NET API。
- 核心命名空间为 `JYPPX.ROCm.MIGraphXSharp`。
- 两个 Core 独立；HIP.Interop 1.0.0 精确依赖 MIGraphX Core 1.0.0 与 HIP Core 1.0.0。
- `RunDeviceIntoAsync` 将结果在同一 Stream 上 D2D 复制到调用者缓冲区，不创建主机输出；不能描述为零拷贝借用。
- Runtime 包版本是 1.0.0，内部引擎是 MIGraphX 2.18.0，依赖系统 ROCm 10.1 计算库、设备数据与驱动。
- Windows 引擎来自项目对 AMD 源码的构建，设备代码针对 gfx1100；Ubuntu 使用 AMD 二进制并调整 ELF 查找路径。不要把 Windows MIGraphX 引擎说成 AMD 官方安装器。
- 1.0 包含 18 个 2.18 可选 API 绑定、动态形状/缓存修复、平台引擎包和图像示例迁移。缺可选导出时明确拒绝对应功能。
- 样例包含 YOLO26 五任务、PaddleOCR v4/v5/v6、CLIP 与 PP-Structure。OpenCV 5.0.0 只影响示例，两个推理库不依赖 OpenCV。
- 不把所有示例都描述为纯 GPU：CLIP 图像处理在 CPU；PP-Structure 公式可显式选择 ORT CPU；各示例分别有处理位置和计时范围。
- 正式发布报告：Windows 189 项托管测试通过；Windows GPU 组合 25 项，Ubuntu/WSL2 七组 30 项通过；量化等有特定矩阵和精度范围。这是对应环境的功能证据，不是任意模型精度或性能证据。
- 2026-11-17 四个 1.0.0 包与 GitHub v1.0.0 已发布。公开包下载与非签名内容比对、仓库签名核对均有发布报告。
- 当前限制：Windows 2×2 INT8 原生崩溃、Windows 缺 TensorFlow importer；历史 Linux 2.15 O3 的 OCKL 问题以显式 O2 规避；这些不同原生版本的条件不能混写。

### 共用的框架和环境表述

托管目标：`net46`、`net461`、`net462`、`net47`、`net471`、`net472`、`net48`、`net481`、`netcoreapp3.1`、`net5.0`、`net6.0`、`net7.0`、`net8.0`、`net9.0`、`net10.0`。

这是包和构建范围，不等于全部旧运行时/GPU 场景已测试。当前正式组合的主要本机 GPU 基线为 Radeon PRO W7900/gfx1100、ROCm 10.1、Windows 和 Ubuntu 24.04/WSL2。旧 Linux ROCm 7.2.1 / MIGraphX 2.15 有独立历史证据。
