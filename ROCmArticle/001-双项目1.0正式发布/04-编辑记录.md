## 两段示例的实际验证

- 验证平台：当前 Windows、.NET SDK 11.0.100（编译目标 net10.0）、本机 Radeon PRO W7900/gfx1100。系统还安装有 .NET SDK 10.0.404。
- 示例代码从正文 C# 代码块提取到 `examples/HipHello` 和 `examples/MigraphxHello`，以保持一致。
- HIP 消费正式 Core 1.0.0 与 Windows Runtime 10.1.0，本地来源为此前公开包验证缓存。实际输出：Runtime 7.16.26385、Driver 7.16.26385、AMD Radeon PRO W7900。进程退出码 0。
- MIGraphX 消费正式 Core 1.0.0 与 Windows Runtime 1.0.0，来源为发布工作区 `nuget-public`。使用系统 ROCm 10.1 的 HIP/HIPRTC、设备数据与数学库配置。加载当前包引擎，从内存解析 Identity ONNX，以 `gpu` target 编译，输出 `1, 2, 3, 4`。进程退出码 0。
- Identity 模型由项目正式源码自带的 PowerShell 生成器输出到本文目录，保留在 `assets/models/identity.onnx` 和运行示例目录。输入/输出 float32[1,4]；该模型验证调用路径，不作 AI 精度或性能基准。
- 初始相对模型路径被托管接口拒绝；改成绝对路径后，本机 Windows 原生文件解析在中文路径下报字符映射错误。最终正文改为 .NET `File.ReadAllBytes` + `ParseOnnxBuffer`，已在当前中文目录通过。两个初始失败日志保留，不算最终示例成功。
- 日志在 `research/validation/`。本次没有重跑两个项目的完整测试矩阵、核验全部原生函数或测试其他 GPU。
- 样例还原使用本地现有公开包缓存，避免重复下载；没有在本次额外复做 NuGet 仓库签名。签名结论仍来自对应发布报告。
