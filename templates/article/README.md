# 新文章模板

在对应系列下新增 `下一编号-主题/`，按需创建以下文件。示例路径中的 `NNN` 需替换为该系列的下一个三位编号；模板本身不占用文章编号。

| 文件或目录 | 内容 |
| --- | --- |
| `00-文章规划.md` | 目标读者、文章目的、核心内容与章节安排 |
| `01-事实与来源.md` | 项目、版本、源码、文档、已确认事实与来源 |
| `02-配图方案.md` | 每张图要表达什么、图片文件与提示词 |
| `03-正文.md` | 文章主文件 |
| `03-正文预览.html` | 可选的本地阅读预览 |
| `04-编辑记录.md` | 日期、调整、发布状态与平台地址 |
| `assets/` | 单篇配图与必要资源 |
| `examples/` | 可运行示例 |
| `research/` | 来源快照、验证资料与历史版本 |

正文起稿可参考以下结构，实际章节按文章类型合并或调整：

```markdown
# 文章标题

一句话说明读者能获得什么。

从具体场景引出项目和本文内容。

## 一、核心主题

## 二、关键能力或实现过程

## 三、上手与示例

## 四、应用与扩展

## 五、项目入口
```

写完后更新本系列 README 和仓库根目录 README。确认链接、图片、版本和示例一致，再推进发布状态。
